# fiel-demo-tienda

Tienda mínima para un demo. Seguí estas reglas.

## Código generado

- Don't edit `src/generated/*`; regenerate with `npm run gen`.

## Datos

- Never run `rm -rf data`; use the reset script. The seed lives in `scripts/db-reset.mjs`.

## Verificación

- Use `npm test` instead of `node --test`.
- After editing code, verify each change with `npm test`.
- Always run `npm run lint`.

## Estilo (no verificable por patrón)

- Responde en español, tono directo.
- No hagas commit ni push a menos que te lo pida.
- Preferí funciones pequeñas y nombres en inglés.
